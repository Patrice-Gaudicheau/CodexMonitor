Windows can hide tray icons in overflow; users should keep CodexMonitor visible as described in the [installation guide](INSTALLATION.md#download-and-run).

The image is below GitHub's 1 MB limit. GitHub recommends 1280 × 640 for best display; see its [Social Preview documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).

### Upload manually

The available repository tools do not expose Social Preview configuration. The image has been prepared locally; no repository setting has been changed.

1. Open the [repository](https://github.com/Patrice-Gaudicheau/CodexMonitor) on GitHub.
2. Select **Settings**.
3. Under **Social preview**, select **Edit → Upload an image**.
4. Choose `docs/images/social-preview.png` from your local checkout and confirm the preview.

The repository owner manages visibility, About settings, and Social Preview upload separately. Uploading the image does not publish a new application release.

[render-social-preview.cjs](images/render-social-preview.cjs) reproduces the PNG on Windows with Segoe UI installed, using Node.js and a separately available `sharp` module. This is a documentation tool, not an application dependency; no package or lock file was added to the application. From the repository root, with `sharp` available to Node:

```powershell
node .\docs\images\render-social-preview.cjs
```

The script checks input dimensions, source hashes, final PNG dimensions, and file size. Fonts are rendered into the PNG rather than distributed. Detailed transient checks remain under ignored `artifacts/documentation-review`.
